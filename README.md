# Personal Portfolio Website

A responsive personal portfolio website built and deployed as part of **CS 3365: Software Engineering** at Texas Tech University. This repository demonstrates a complete Git/GitHub workflow, including feature branching, incremental commits, and automated deployment via GitHub Pages.

## 🚀 Live Demo
View the live website here: [https://salarapo.github.io/create_website/]

---

## 📌 Project Overview
This project serves as an interactive showcase of my academic background, technical projects, and skills. The primary goal of this repository is to demonstrate proper software engineering version control practices using Git from the command line.

### Key Sections Included:
* **Home / Intro:** Brief welcome and academic major overview.
* **About Me:** Information about my background, career goals, and interests.
* **Skills:** Summary of technical, programming, and software tools.
* **Projects:** Descriptions and details of featured computer science projects.
* **Contact:** Professional contact information and links to external profiles.

---

## 🛠️ Technologies Used
* **Languages:** HTML5, CSS3, JavaScript
* **Version Control:** Git, GitHub
* **Deployment:** GitHub Pages
